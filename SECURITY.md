# Security Policy

## Scope

This is an alpha project. It has not undergone an independent security audit, and no security guarantee is made.

## Reporting a vulnerability

Please do not publish sensitive details, personal profile data, real PDFs, candidate passwords, or database files in public issues. Until a private security contact is configured for the repository, report only that a security issue exists in a public issue and ask maintainers to arrange a private channel.

## Protect local data

Profile files may contain names, dates of birth, government identifiers, phone numbers, email addresses, and account identifiers. Keep them local and private. Never commit real profile files or profile exports. Use synthetic test data. Before publishing, inspect the full commit diff and repository history for secrets.

Only use PDF Unlocker on files you own or are authorized to access.
